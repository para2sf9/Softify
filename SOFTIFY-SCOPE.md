# Softify Scope Map

## Covered in this runnable build

| Lifecycle area | Module |
|---|---|
| Portfolio / project management | Projects |
| SDLC models and delivery health | Project methodology and lifecycle fields |
| Requirements engineering | Requirements, versions, acceptance criteria, risk |
| Traceability | Requirement → test case → defect matrix |
| STLC planning | Test plans, scope, strategy, entry/exit criteria |
| Test design | Test cases, steps, expected results, priority and automation status |
| Test execution | Runs, builds, environments, pass/fail/blocked results |
| QA | Process audits, standards, release gates and metrics |
| QC | Asset inspection, execution, defects and evidence-oriented records |
| Defect management | Severity, priority, workflow, ownership and root cause |
| Security | SAST/DAST/SCA/etc. findings, CVSS, CWE and remediation |
| Automation | Cross-tool execution result repository |
| Testing tools | Web, API, mobile, performance, security, code quality and CI/CD catalog |
| Environments | Dev through production health and deployment versions |
| Releases | Readiness, target dates and quality gates |
| Documentation | BRD/SRS/SDS/strategy/plan/RTM/SOP/release/security document records |
| Reporting | Dashboard, summary analytics and authenticated CSV exports |
| AI assistance | Local rule-assisted test generation and defect analysis |
| Security architecture | JWT, RBAC, scrypt, validation, headers, rate limit and audit events |

## Production expansion points

- PostgreSQL multi-tenant schema and migrations
- Real object/file storage and antivirus scanning
- SSO, MFA, SCIM and fine-grained project membership
- Background workers and tool-specific adapters
- Immutable audit ledger and compliance evidence retention
- Webhooks, notifications, comments, approvals and subscriptions
- Real-time pipeline streaming and distributed test execution
- Secrets-manager integration
- Advanced analytics warehouse
- External LLM integration with privacy controls, evaluation and human approval
